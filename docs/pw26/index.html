01 · DAS PRINZIP

Wie funktioniert Vibe Coding?

01

Beschreiben

Du erklärst in normaler Sprache, was deine Anwendung können soll.

02

Generieren

Eine KI erstellt daraus HTML, CSS, JavaScript oder andere Dateien.

03

Testen

Du probierst das Ergebnis aus und beschreibst, was geändert werden soll.

04

Iterieren

Die KI verändert das Projekt Schritt für Schritt, bis das Ergebnis passt.

02 · VIBE CODING LAB

Beschreibe eine kleine Website oder Anwendung. In der echten Version wird dein Prompt an das Backend geschickt und dort von einer Coding-KI verarbeitet.

Demo-Modus

Demo: Die Vorschau wird lokal aus deinem Prompt simuliert. Später ersetzt du die Demo-Funktion durch deinen API-Aufruf.

03 · MEIN PROJEKT

Was untersuche ich?

Meine Forscherfrage lautet:

„Wie funktioniert Vibe Coding?“

Ich untersuche

wie aus natürlichen Anweisungen funktionierender Code entsteht, wie viele Schritte dafür nötig sind und welche Aufgaben weiterhin vom Menschen übernommen werden.

Ich dokumentiere

Prompts, Versionen, Fehler, Verbesserungen und die Grenzen des Systems. So wird aus der Demo eine eigene Untersuchung.
