Vibe Coding beschreibt einen Entwicklungsstil, bei dem du einer KI in natürlicher Sprache sagst, was eine Anwendung tun und wie sie funktionieren soll. Die KI erzeugt daraus den Code.

01 — GRUNDLAGE

Wie es funktioniert

Der Ablauf ist eher ein Dialog als klassisches Programmieren Zeile für Zeile.

Beschreiben

Du formulierst dein Ziel: zum Beispiel ein Portfolio, ein Spiel oder ein Dashboard.

Generieren

Ein Sprachmodell übersetzt die Beschreibung in HTML, CSS, JavaScript oder andere passende Bestandteile.

Prüfen

Du testest das Ergebnis, beschreibst Änderungen und lässt den Code weiterentwickeln.

Verbessern

Durch weitere Prompts entsteht schrittweise eine Anwendung, die genauer deinen Vorstellungen entspricht.

02 — ANWENDUNG

Wer es benutzt

Vibe Coding kann unterschiedliche Rollen unterstützen – nicht nur klassische Softwareentwickler.

Schüler & Einsteiger

Ideen können schnell als funktionierende Prototypen ausprobiert werden, auch wenn noch wenig Programmiererfahrung vorhanden ist.

Entwickler

KI kann beim Erstellen von Code, beim Debugging und bei wiederkehrenden Aufgaben unterstützen.

Designer

Oberflächen und Interaktionen lassen sich direkt aus visuellen und funktionalen Beschreibungen entwickeln.

Teams & Lehrkräfte

Prototypen und Lernprojekte können schneller erstellt und anschließend gemeinsam untersucht werden.

03 — KRITISCHE SEITE

Gefahren

Generierter Code ist nicht automatisch richtig, sicher oder für den konkreten Zweck geeignet.

Fehler & Halluzinationen

KI kann Code erzeugen, der plausibel aussieht, aber nicht korrekt funktioniert oder auf falschen Annahmen beruht.

Sicherheitslücken

Generierter Code kann unsichere Praktiken enthalten. Bei echten Anwendungen müssen Ergebnisse geprüft und getestet werden.

Datenschutz

Prompts und Quellcode können sensible Informationen enthalten. Vor dem Hochladen sollte geprüft werden, welche Daten übertragen werden.

Zu viel Vertrauen

Wer nur akzeptiert, was die KI ausgibt, kann Fehler übersehen. Menschliche Kontrolle bleibt wichtig.

05 — PROJEKT

Über das Projekt

Diese Website verbindet Erklärung und Experiment: Erst wird Vibe Coding erklärt, danach kann der Ablauf selbst ausprobiert werden.

Frontend

Die Oberfläche läuft als statische Website und enthält Erklärungen, Lab und Vorschau.

Server

Der Backend-Server nimmt den Prompt entgegen und fordert beim KI-Modell eine HTML-Anwendung an.

Vorschau

Das erzeugte HTML wird in einer isolierten Vorschau angezeigt. Temporäre Projekte haben eine begrenzte Laufzeit.

Veröffentlichen

Ein Projekt kann bewusst veröffentlicht werden und bleibt dann über einen öffentlichen Code erreichbar.
