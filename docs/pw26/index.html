Vibe Coding beschreibt einen Entwicklungsstil, bei dem du einer KI in natürlicher Sprache sagst, was eine Anwendung tun und wie sie funktionieren soll. Die KI erzeugt daraus den Code.

01 — GRUNDLAGE

Wie es funktioniert

Der Ablauf ist eher ein Dialog als klassisches Programmieren Zeile für Zeile.

KI Tool auswählen

Das KI Coding Tool wird ausgesucht, um Code zu erzeugen, Fehler analysieren oder Befehle ausführen kann.

Ziel und Kontext beschreiben

Der Nutzer beschreibt, was der Code machen soll. Wichtig dabei sind Funktionen und das gewünschte Design.

Code generieren lassen

Die KI erzeugt denn ersten Code. Das kann ein Entwurf sein, oder direkt fertige Dateien.

Ergebnis überprüfen und verbessern

Wenn der Nutzer unzufrieden mit der Anwendung ist, gibt er der KI weitere Anweisungen.

02 — ANWENDUNG

Wer es benutzt

Vibe Coding kann unterschiedliche Rollen unterstützen – nicht nur klassische Softwareentwickler.

Schüler & Einsteiger

Ideen können schnell als funktionierende Prototypen ausprobiert werden, auch wenn noch wenig Programmiererfahrung vorhanden ist.

Entwickler

KI kann beim Erstellen von Code, beim Testen und bei wiederkehrenden Aufgaben unterstützen.

Designer

Oberflächen und Interaktionen lassen sich direkt aus visuellen und funktionalen Beschreibungen entwickeln.

Teams & Lehrkräfte

Prototypen und Lernprojekte können schneller erstellt und anschließend gemeinsam untersucht werden.

03 — KRITISCHE SEITE

Nachteile

Generierter Code ist nicht automatisch richtig, sicher oder für den konkreten Zweck geeignet.

Sicherheit

KI Generierter Code heißt nich automatisch dass alles Sicher ist. Sie macht das was man ihr sagt. Dadurch entstehen Sicherheitslücken.

Fehler und Performance

KI Generiert oft mit dem bloßem Auge unsichtbare Fehler. Zudem ist der Code oft nicht gut optimiert, da KI mit echtem Code trainiert wurde, der wiederum schlecht optimiert ist.

Wartung und Lesbarkeit

Da der Code nicht Lesbar ist, können Menschen den Code nachträglich schlecht bearbeiten. Dadurch wird der Code KI abhängig.

Zu viel vertrauen

Mit der Zeit vertraut der Nutzer immer mehr Vibe Coding und wird immer abhängiger.

05 — PROJEKT

Über das Projekt

Diese Website verbindet Erklärung und Experiment: Erst wird Vibe Coding erklärt, danach kann der Ablauf selbst ausprobiert werden.

Frontend

Die Oberfläche läuft als statische Website und enthält Erklärungen, Lab und Vorschau.

Server

Der Backend-Server nimmt den Prompt entgegen und fordert beim KI-Modell eine HTML-Anwendung an.

Vorschau

Das erzeugte HTML wird in einer isolierten Vorschau angezeigt. Temporäre Projekte haben eine begrenzte Laufzeit.

Veröffentlichen

Ein Projekt kann bewusst veröffentlicht werden und bleibt dann über einen öffentlichen Code erreichbar.
